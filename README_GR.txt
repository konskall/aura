AURA — UI Visual Reference Lock v4.0
====================================

Αυτό το πακέτο περιλαμβάνει:
  - AURA_UI_Visual_Reference_Lock_v4.md
  - design/reference/aura_ui_target.png (Η αρχική σου εικόνα, χωρίς αλλαγές)
  - design/reference/panels/01-home.png έως 18-voice.png

Οδηγίες:
1) Αποσυμπίεσε το ZIP ΜΕΣΑ στον υπάρχοντα φάκελο του project AURA.
2) Μην αντικαταστήσεις τον πηγαίο κώδικα ή τα λειτουργικά αρχεία της εφαρμογής.
3) Άνοιξε το Codex ή το Claude Code με working directory το AURA project.
4) Γράψε:

Read AURA_UI_Visual_Reference_Lock_v4.md and open
`design/reference/aura_ui_target.png` with your image viewing capability.
Treat the image as the authoritative visual specification, overriding
conflicting earlier UI creative directions. Implement the redesign in
existing LVGL code; run simulator, capture actual 480x480 screenshots,
compare to all 18 reference panels, and iterate. Do not stop at planning.

ΣΗΜΑΝΤΙΚΟ:
Η Waveshare έχει πραγματική τετράγωνη οθόνη 480x480.
Η κυκλική διάταξη της εικόνας αναπαράγεται ΕΣΩΤΕΡΙΚΑ στην τετράγωνη
οθόνη (μαύρες γωνίες), χωρίς να απαιτείται κυκλικό hardware.

Τα reference panels είναι για οπτική ανάλυση, όχι για απευθείας χρήση
ως screenshots αντί πραγματικών interactive controls.
